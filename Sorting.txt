1. Student Marks Sorting (Bubble Sort)

Question: A teacher wants to arrange student marks in ascending order.

Input:

[75, 90, 65, 85, 70]

Output:

[65, 70, 75, 85, 90]


a=[75, 90, 65, 85, 70]

for i in range(len(a)):
    for j in range(len(a)-1):
        if a[j] > a[j+1]:
            a[j], a[j+1] = a[j+1], a[j]

print(a)

6. Card Sorting (Insertion Sort)

Question: Sort cards in a player's hand.

Input:


[7, 3, 9, 1, 5]

Output:

a = [7, 3, 9, 1, 5]

for i in range(1, len(a)):
    key = a[i]
    j = i - 1

    while j >= 0 and a[j] > key:
        a[j+1] = a[j]
        j -= 1

    a[j+1] = key

print(a)

[1, 3, 5, 7, 9]

9. Student Record Sorting (Merge Sort)

Question: Sort student records efficiently.

Input:

[55, 12, 89, 34, 23, 78]

Output:

def merge_sort(a):
    if len(a) > 1:
        mid = len(a) // 2
        l = a[:mid]
        r = a[mid:]

        merge_sort(l)
        merge_sort(r)

        i = j = k = 0

        while i < len(l) and j < len(r):
            if l[i] < r[j]:
                a[k] = l[i]
                i += 1
            else:
                a[k] = r[j]
                j += 1
            k += 1

        while i < len(l):
            a[k] = l[i]
            i += 1
            k += 1

        while j < len(r):
            a[k] = r[j]
            j += 1
            k += 1

a = [55, 12, 89, 34, 23, 78]
merge_sort(a)
print(a)

[12, 23, 34, 55, 78, 89]

11. Product Search Result Sorting (Quick Sort)

Question: Sort product prices.

Input:

[1000, 200, 1500, 500, 800]

Output:

def quicksort(a):
    if len(a) <= 1:
        return a
    pivot = a[0]
    left = [x for x in a[1:] if x <= pivot]
    right = [x for x in a[1:] if x > pivot]
    return quicksort(left) + [pivot] + quicksort(right)

a = [1000, 200, 1500, 500, 800]
print(quicksort(a))

[200, 500, 800, 1000, 1500]
